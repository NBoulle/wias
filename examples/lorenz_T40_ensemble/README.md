# Lorenz: bounds versus percentage of 100 random inputs

This experiment evaluates Lorenz coefficient identification at final time
`T = 40`. The figure has percentage of sampled inputs on the horizontal axis
(0–100) and the condition-number or relative coefficient-error bound on the
vertical axis (logarithmic).

## Reproduce

From the `wias` repository:

```sh
/Users/nboulle/Documents/venv-firedrake/bin/python examples/10_lorenz_T40_ensemble.py
```

Equivalently, activate the Firedrake environment and run the script with
`python`. The experiment needs NumPy, SciPy, Matplotlib, and the local WIAS
source modules. It does not initialize Firedrake or PETSc. By default all
outputs are saved beside this README in `examples/lorenz_T40_ensemble/`.

## Experimental settings

- 100 independent initial conditions, uniform on `[-10,10]^3`, generated by
  `numpy.random.default_rng(42)`. These are the first 100 draws from the same
  generator and law as `09_lorenz_final_time.py`.
- Lorenz parameters `(sigma, rho, beta) = (10, 28, 8/3)`; no added measurement
  noise; all three state components are observed.
- DOP853 integration with relative tolerance `1e-10`, absolute tolerance
  `1e-12`, and continuous dense output on `[0,40]`.
- Ten dictionary terms `[1,x,y,z,x^2,xy,xz,y^2,yz,z^2]`, 50 tests
  `sin(k*pi*t/40)`, and composite Simpson quadrature. The primary figure uses
  `dt = 0.01`, matching the response's observation-window ensemble script.
  This differs from the SI's original single-trajectory `dt = 0.001` example.
- The recovery matrix is the full `50 x 10` tested dictionary matrix. Its
  condition number is computed before numerical column reduction, with no
  column rescaling. Coefficients are recovered with the actual WIAS
  `CPQR_solver`, using its `1e-10` relative rank tolerance. Every sample has
  numerical rank 10 at all three quadrature resolutions.
- Error means `||C_hat - C||_F / ||C||_F`, for the full `3 x 10` coefficient
  matrix, including coefficients whose true values are zero.

## Empirical bounds

| Percentage | Condition number at most | Relative coefficient error at most |
|---:|---:|---:|
| 50% | 45,260 | 2.912e-6 |
| 90% | 79,720 | 8.014e-6 |
| 95% | 100,200 | 1.064e-5 |
| 99% | 130,000 | 1.756e-5 |
| 100% | 252,400 | 2.475e-5 |

For percentage `p > 0`, the plotted bound is order statistic
`ceil(100*p/100)` of the 100 observed values. The curve's convention at zero
is the sample minimum. Tabulated bounds are rounded upward to four
significant figures, and the claimed coverage is checked against every
stored sample. The 50% order statistic need not equal NumPy's interpolated
sample median.

The two columns describe **separate marginal coverage**. For example, 95
samples satisfy the condition bound and 95 satisfy the error bound; 91
samples satisfy both of those bounds simultaneously. All 100 satisfy both
of the final row's bounds. These are finite-sample observations, not
population guarantees or Gaussian-input conclusions. No extrapolation
beyond the observed upper tail is made.

## Numerical verification

All 100 trajectories were reassembled using `dt = 0.005` and `dt = 0.001`
on the same dense numerical trajectories. The largest relative change in
condition number between `dt = 0.01` and `dt = 0.001` was `1.44625e-5`
(approximately 0.00145%).

| Quadrature spacing | Median relative error | Maximum relative error |
|---:|---:|---:|
| 0.01 | 2.91627e-6 | 2.47417e-5 |
| 0.005 | 1.82874e-7 | 1.56059e-6 |
| 0.001 | 3.11073e-10 | 2.51293e-9 |

The median decreases by approximately a factor of 16 on halving the
primary quadrature spacing. Thus the primary coefficient errors are strongly
affected by numerical quadrature; they do not represent an intrinsic noise
floor. This refinement study holds the numerical trajectory fixed and does
not certify the exact Lorenz trajectory at long times.

The accelerated Simpson assembly was checked against WIAS
`build_weak_system` for all three components and all three spacings on the
first sample. Two full runs produced identical numerical arrays. Solver
failure raises an exception rather than silently dropping or resampling an
input. Original WIAS source files and the current manuscript/referee-response
files were preserved.

## Suggested text for the referee response

> To quantify the frequency of poor conditioning, we sampled 100 independent
> initial conditions uniformly from [-10,10]^3 and performed Lorenz
> identification on [0,40], using 50 sinusoidal test functions and composite
> Simpson quadrature with spacing 0.01. We plot the empirical bound as a
> function of the percentage of sampled inputs, separately for the recovery
> matrix condition number and relative coefficient error. The condition
> number was at most 79,720 for 90% of the samples, at most 100,200 for 95%,
> and at most 252,400 for all 100 samples. Separately, the relative Frobenius
> coefficient error was at most 1.064e-5 for 95% of the samples and at most
> 2.475e-5 for all samples. Refining quadrature to spacing 0.001 changed each
> condition number by less than 0.00145% relative to the primary result and
> reduced the maximum coefficient error to 2.513e-9. These results quantify
> the observed distribution for the stated input law and numerical procedure;
> they do not establish a uniform bound over all admissible inputs.
